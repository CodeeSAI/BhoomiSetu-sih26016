About
BhoomiSetu is a unified platform for managing the land acquisition lifecycle from one operational dashboard.
It connects land records, GIS, projects, statutory workflows, compensation, affected families and rehabilitation.
Land → GIS → Projects → Approvals → Compensation → R&R → Monitoring
Key Features
Command Center — Project and acquisition overview
GIS & ULPIN — Parcel visualization and acquisition status
Affected Families — Family, displacement and R&R tracking
Workflow Governance — Statutory stages and approvals
Compensation — Assessment and disbursement tracking
Analytics — Progress and bottleneck insights
Role-Based Access — Controlled administrative workflows

Acquisition Lifecycle
Project Initiation → Land Identification → GIS / ULPIN Verification → Digital Scrutiny → Field Verification → Statutory Approvals → Notifications → Objection / Hearing → Declaration & Award → Compensation → R&R → Possession → Monitoring
Why BhoomiSetu?
Land acquisition involves multiple departments, projects, approvals, finances and affected families.
BhoomiSetu brings them together in one connected operational view.
LAND + PROJECTS + GIS + PEOPLE + FINANCE + R&R + GOVERNANCE
